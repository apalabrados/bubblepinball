## やめられない理由

- **どのテーブルも新しい挑戦。** それぞれのレイアウト、おもちゃ、ミッション。そして一打ごとに判断を迫るタイマー。
- **反撃してくるボス。** 巨大なボスがゾーンを守る。フェーズ、攻撃、そして最後の抵抗。
- **いつも新しい何か。** 専用のマシン、音楽、ボス、おもちゃを持った世界がまるごと届く。
- **困ったときのお助け。** 行き詰まったらブルブがぴったりのお助けを光らせる：ピン、レインボーボール、マグネット、追加の秒数。
- **サクッと遊べる。** 1テーブル数分。もう1回？もちろん。

## ブルブ（Burbu™）だよ

**Burbu™（ブルブ）** は青いガラスのバブルで、Bubble Pinball™ でのきみの相棒。応援してくれて、テーブルが難しくなるとヒントをくれて、勝つたびに一緒に喜んで、世界ごとに新しいコスチュームを着る。一緒に遊ぶほど、仲良くなれる。
